# 功能点清单｜小型门诊信息管理系统
依据：《医院信息系统功能规范（2002版）》
角色：admin / doctor / cashier / pharmacist

## 一、系统管理【必做】
- [√] 用户账号CRUD，四类RBAC角色
- [√] JWT登录，bcrypt哈希存储密码，禁止明文
- [√] 全局审计日志中间件，记录登录、挂号、处方、收费、发药
- [ ] 数据定时备份；不实现，理由：课程设计开发资源有限

## 二、门诊挂号子系统【必做】
- [√] 管理员维护医生排班Schedule
- [√] 号源自动计算、号源扣减（数据库事务）
- [√] 患者挂号生成Registration挂号记录
- [√] 挂号记录查询

## 三、门诊医生工作站【必做】
- [√] 医生查看自己的待接诊挂号患者
- [√] 创建处方Prescription，支持多条处方明细PrescriptionItem
- [√] 处方绑定ICD-10疾病编码、诊断名称
- [√] 权限校验：仅doctor角色允许开具处方

## 四、门诊收费子系统【必做】
- [√] 后端处方自动划价，不采信前端传入价格
- [√] 收费接口数据库事务：生成收费单ChargeOrder，标记处方paid=True
- [√] 收费记录查询

## 五、药房药品管理【必做】
- [√] 药品档案五要素（通用名、商品名、规格、剂型、医保类别、stock库存）
- [√] CSV批量药品导入，服务端校验，返回错误明细
- [√] 发药接口；仅已收费处方允许发药；库存不足返回400，事务回滚

## 六、统计报表【必做】
- [√] 今日挂号量、今日收费金额汇总统计接口

## 七、选做加分
- [ ] pytest三层测试：单元+API+Playwright E2E主流程
- [ ] docker-compose本地一键启动；公网HTTPS部署
